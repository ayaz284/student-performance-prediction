# 🎓 Student Performance Prediction

A Machine Learning based web application that predicts a student's
expected final academic score using factors such as study hours,
attendance, previous exam score, assignments, sleep hours, and
extracurricular activities.

The project uses Python, Scikit-learn, Pandas, Matplotlib, and Streamlit.

---

## 📌 Project Overview

Student academic performance can be influenced by several factors.

This project uses Machine Learning to analyze student-related data
and predict the expected final score.

The application provides:

- Student performance prediction
- Dataset analysis
- Interactive charts
- Machine Learning model comparison
- Performance classification
- Professional Streamlit dashboard

---

## 🎯 Objectives

The main objectives of this project are:

1. Collect and prepare student data.
2. Analyze factors affecting student performance.
3. Train Machine Learning regression models.
4. Compare different Machine Learning algorithms.
5. Predict a student's expected final score.
6. Build an interactive web application.

## 📊 Dataset

The project uses a synthetic dataset created for educational purposes.

The dataset contains 200 student records.

### Features

| Feature | Description |
|---|---|
| study_hours | Daily study hours |
| attendance | Attendance percentage |
| previous_score | Previous examination score |
| assignments_completed | Number of completed assignments |
| sleep_hours | Daily sleep hours |
| extracurricular | Participation in extracurricular activities |
| final_score | Final academic score |
